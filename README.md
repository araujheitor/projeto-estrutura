# Subsolo — Operação Estrutura Escondida

Site educacional interativo criado a partir do memorando da “Missão 4”. O painel permite selecionar pontos, alterar leituras simuladas de radar, recalcular um índice de evidência, exportar os dados e imprimir o pré-relatório.

## Como abrir

Abra `index.html` em qualquer navegador moderno. Não é necessário instalar dependências nem iniciar servidor.

## Importante

Os pontos do mapa são demonstrativos e reproduzem apenas o padrão narrado no material: sinais fortes ao sul, contorno incompleto e pouca variação de profundidade. Eles não são medições reais. O índice é didático e não substitui interpretação geofísica profissional.
